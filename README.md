# Curious Learner — Personal homepage

A standalone homepage using the nickname Curious Learner, with an introduction and a learning notebook about Git, web pages, and the agent loop.

## Preview

Open `index.html` in a browser. The page, styles, icon, and illustration work locally without installing packages or connecting to the Internet.

For an HTTP preview, run this command from this directory with Python 3:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000. Press Ctrl+C to stop the server.

## Files

- `index.html`: page content and the original inline SVG illustration.
- `style.css`: responsive layout, typography, focus styles, and reduced-motion support.
- `favicon.svg`: local page icon.
- `README.md`: preview instructions.

Runtime dependencies: none. No build process, package manifest, lockfile, or external asset service is needed.
